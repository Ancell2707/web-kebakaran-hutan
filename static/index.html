Tentang Pantau Api

Pantau Api adalah web pemantauan titik panas (hotspot) kebakaran hutan dan lahan di Indonesia. Data hotspot berasal dari satelit NASA FIRMS (VIIRS) dan diperbarui otomatis, dilengkapi layer angin, kelembapan, kualitas udara (AQI), statistik per provinsi, serta laporan warga yang diverifikasi admin.

Sumber data: NASA FIRMS. Proyek mahasiswa Informatika Universitas Mulawarman.
